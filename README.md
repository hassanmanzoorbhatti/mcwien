# MC Wien website concept

Independent German-language landing page by Hassan Manzoor, following the Zahnraum composition with original MCW branding, Roboto typography and workshop photography.

Static HTML/CSS/JS, no build or dependencies. GitHub main is linked to Vercel.

## Contact behavior
Telephone links open the dialer. E-mail buttons open the visitor's mail app and do not submit an online booking. A workshop appointment needs personal confirmation. External maps/reviews load only after a click.
